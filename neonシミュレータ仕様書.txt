あります。現在のHTMLでは、ネオン管の周囲に広がる「光芒」は、主に `drawNeonTube()` のこの部分で作っています。

```javascript
// 外側ハロー
for (let r = w * 5; r >= w; r -= 3) {

    const alpha =
        map(r, w, w * 5, 40, 2);

    stroke(red(c), green(c), blue(c), alpha);
    strokeWeight(r);

    line(x, top, x, bottom);
}
```

ここを調整すると、かなり自由にネオンらしさを変えられます。

### 1．光芒の「広がる範囲」

一番重要なのが、

```javascript
r = w * 5
```

の **`5`** です。

これは、ネオン管本体の太さ `w` に対して、どこまで外側へ光を広げるかを決めています。

例えば、

```javascript
w * 3
```

にすると、

・光芒の範囲が狭い
・ネオン管がシャープに見える
・周囲への影響が小さい
・看板の文字などに向く

一方、

```javascript
w * 8
```

にすると、

・かなり広い範囲に光が漏れる
・ネオン管の周囲が大きく明るくなる
・派手でラスベガス的になる
・管そのものの輪郭は少しぼやけて見える

という変化になります。

---

### 2．光芒の「濃さ」

こちらが、

```javascript
map(r, w, w * 5, 40, 2)
```

の

```javascript
40
```

です。

これは**管に近い部分の光の濃さ（透明度）**です。

例えば、

```javascript
map(r, w, w * 5, 80, 2)
```

とすると、管のすぐ周囲がかなり明るくなります。

逆に、

```javascript
map(r, w, w * 5, 20, 2)
```

なら、淡い光になります。

つまり、

```text
40 → 80
```

にすると、

**「ぼわっと強く光るネオン」**

になります。

---

### 3．光芒の外側をどれくらい残すか

最後の

```javascript
2
```

も重要です。

```javascript
map(r, w, w * 5, 40, 2);
```

では、外側に行くほど透明度が

```text
40 → 2
```

と薄くなっています。

例えば、

```javascript
map(r, w, w * 5, 40, 8);
```

とすると、外側にもかなり光が残ります。

そのため、

**光の範囲が広く、遠くまでぼんやり照らす感じ**

になります。

逆に、

```javascript
map(r, w, w * 5, 40, 0);
```

なら、外側は急速に消えていきます。

---

### 4．光芒を何段階で描くか

これも意外に効きます。

```javascript
for (let r = w * 5; r >= w; r -= 3)
```

の

```javascript
r -= 3
```

です。

これは光芒を描く「輪」の間隔です。

```javascript
r -= 5
```

なら少ない段階で描くので、軽くなります。

```javascript
r -= 2
```

なら細かく描くので、より滑らかな光になります。

ただし、ここは**光の広がりそのものより、光芒の滑らかさ**に効くパラメータです。

---

## さらに重要なのが「ネオン管そのものの太さ」

この部分です。

```javascript
const tubeWidth = max(7, min(18, width / 75));
```

ここで、

```javascript
7
```

が最小太さ、

```javascript
18
```

が最大太さです。

例えば、

```javascript
const tubeWidth = max(10, min(24, width / 65));
```

とすれば、管そのものが太くなります。

そして先ほどの

```javascript
w * 5
```

は、この `w` を基準にしているので、**管を太くすると光芒も連動して広がります。**

---

## 私なら最初にこの4個を触ります

現在：

```javascript
for (let r = w * 5; r >= w; r -= 3) {

    const alpha =
        map(r, w, w * 5, 40, 2);

    stroke(red(c), green(c), blue(c), alpha);
    strokeWeight(r);

    line(x, top, x, bottom);
}
```

これを調整するなら、

| パラメータ    | 現在値 | 効果        |
| -------- | --: | --------- |
| `w * 5`  |   5 | 光芒の広がる範囲  |
| `40`     |  40 | 管の近くの光の強さ |
| `2`      |   2 | 光芒の外側に残る光 |
| `r -= 3` |   3 | 光芒の滑らかさ   |

です。

### 例えば「派手なラスベガス風」

```javascript
for (let r = w * 8; r >= w; r -= 2) {

    const alpha =
        map(r, w, w * 8, 55, 3);

    stroke(red(c), green(c), blue(c), alpha);
    strokeWeight(r);

    line(x, top, x, bottom);
}
```

かなり**「光そのものが空間に漏れ出している」**感じになります。

逆に、

```javascript
for (let r = w * 3; r >= w; r -= 3) {

    const alpha =
        map(r, w, w * 3, 30, 0);

    stroke(red(c), green(c), blue(c), alpha);
    strokeWeight(r);

    line(x, top, x, bottom);
}
```

なら、かなりシャープなネオン管になります。

なお、現在の描画方式は「ぼかしフィルター」ではなく、**太さの違う半透明の線を何本も重ねて擬似的なグローを作っている**方式です。したがって、上の4パラメータをいじるだけでも、かなり大きく雰囲気を変えられます。
